# Outputs

This directory contains the four aggregate PNG artefacts generated by the source visualisation workflow.

```powershell
python Source\Visualisation\GenerateBrainAgeFigures.py
```

The exact contents of `Outputs/Figures/BrainAge/` are:

```text
table1_demographic_characteristics.png
figure1_predicted_vs_actual_age.png
figure2_gap_distribution_by_diagnosis.png
figure3_calibration_curves.png
```

No PDF files are generated. Subject-level estimates and model tables remain under `Data/Processed/Analysis/BrainAgeResults/` and are excluded from version control with other processed ADNI-derived data.
